# Peel

An internal Avride tool for print-ready decals: pick a decal for a car or a robot, enter the numbers or how many cars you need, and download a PDF or ZIP that is ready for printing and plotter cutting.

**Open Peel:** https://akandilyan.github.io/peel/

The site is static — PDFs and ZIPs are generated right in the browser.

Built with Next.js, [Fluid Functionalism](https://www.fluidfunctionalism.com/), `pdf-lib` and `fflate`.
